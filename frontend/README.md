# Frontend

The frontend is built with Vue.js and Vite for a fast development experience and modular component structure. The UI is designed to be accessible and user-friendly, helping users track pre-surgery steps easily.

- **Framework:** Vue.js
- **Build Tool:** Vite
- **Focus:** Accessibility and clarity for all users.

## Project Setup

From the repository root, install all project dependencies with:

```sh
npm run setup
```

Or install only the frontend dependencies from this folder:

```sh
npm install
```

### Compile and Hot-Reload for Development

From the repository root:

```sh
npm run start:frontend
```

Or from this `frontend` folder:

```sh
npm run dev
```

Vite will print the local URL, usually `http://localhost:5173`.

### Compile and Minify for Production

```sh
npm run build
```
